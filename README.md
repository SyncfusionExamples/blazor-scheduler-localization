# Blazor Scheduler Localization Examples

## Repository Description

This repository contains practical examples demonstrating localization features of Syncfusion Blazor Scheduler component in .NET8 Blazor Web App applications. The examples showcase how to implement multi-language support and regional customization for calendar events and scheduler UI elements.

## Overview

LocalizationScheduler examples showing localization of Syncfusion Blazor Scheduler in .NET8 Blazor Web App application. This project demonstrates best practices for implementing scheduler localization with various culture and language configurations.

## Features

* Support for multiple languages and cultures
* Localized event and calendar displays
* Regional date and time formatting
* Customizable resource files (RESX)
* .NET8 Blazor Web App compatibility

## Prerequisites

* Visual Studio 2022
* .NET 8 or later
* Syncfusion Blazor NuGet packages

## How to run the project

* Checkout this project to a location in your disk.
* Open the specified application from the following folder `.NET8 Blazor Web App`.
* Restore the NuGet packages by rebuilding the solution.
* Run the project.

> Always use latest resource (resx) files from [blazor locale](https://github.com/syncfusion/blazor-locale) repo.
